# emteegee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-player, mobile-first Magic: The Gathering game in the browser — six themed decks, a three-tier bot called The Magician, real touch controls, animation, and sound.

**Architecture:** An event-sourced pure rules engine (`reduce(state, action) -> {state, events}`) with zero DOM knowledge, wrapped by a DOM/CSS-transform UI that consumes emitted events on a timeline. The bot searches by calling the same reducer it plays through. Card behavior is declarative data drawn from a closed effect vocabulary, validated at build time against a mechanic whitelist.

**Tech Stack:** TypeScript, Vite, Vitest. No UI framework. Web Audio for sound. Scryfall for card data and art, resolved at build time only.

**Spec:** [`docs/superpowers/specs/2026-08-10-emteegee-design.md`](../specs/2026-08-10-emteegee-design.md)

---

## Prime directive for every task

**The type contract in Task 2 is law.** Every later task imports from `src/engine/types.ts` and must not
redefine, widen, or shadow those types. If a task genuinely needs a new type, it is added to
`types.ts` in that task and the change is called out in the commit message.

`legalActions(state)` is the single source of truth for legality. The UI, the bot, and the tests all
consult it. If you find yourself writing a second legality check anywhere, stop — that is the bug.

```ts
export type PlayerId = 0 | 1;
export type CardId = string;        // unique per instance, e.g. "serra-angel#3"
export type OracleId = string;      // shared by all copies, e.g. "serra-angel"

export type Color = 'W' | 'U' | 'B' | 'R' | 'G';
export type ManaCost = Partial<Record<Color | 'C', number>>; // C = generic

export type Keyword =
  | 'flying' | 'reach' | 'vigilance' | 'haste' | 'trample'
  | 'first strike' | 'double strike' | 'deathtouch' | 'lifelink'
  | 'menace' | 'defender' | 'ward' | 'hexproof' | 'flash';

export type CardType = 'creature' | 'instant' | 'sorcery' | 'enchantment' | 'artifact' | 'land';
export type Zone = 'library' | 'hand' | 'battlefield' | 'graveyard' | 'exile' | 'stack';

export type Phase =
  | 'untap' | 'upkeep' | 'draw' | 'main1'
  | 'beginCombat' | 'declareAttackers' | 'declareBlockers' | 'firstStrikeDamage' | 'combatDamage' | 'endCombat'
  | 'main2' | 'end' | 'cleanup';

/** Where an effect may point. Resolved by actions.ts, never by the UI. */
export interface TargetFilter {
  zone?: Zone;
  controller?: 'you' | 'opponent' | 'any';
  cardTypes?: CardType[];
  subtypes?: string[];
  colors?: Color[];
  minPower?: number;
  maxPower?: number;
  tapped?: boolean;
  attacking?: boolean;
  blocking?: boolean;
}

export type Duration = 'endOfTurn' | 'permanent';

/** The closed effect vocabulary. Adding a member here is a spec change. */
export type Effect =
  | { kind: 'damage'; target: TargetFilter | 'player' | 'self'; amount: number }
  | { kind: 'destroy'; target: TargetFilter }
  | { kind: 'exile'; target: TargetFilter }
  | { kind: 'draw'; player: 'you' | 'opponent'; count: number }
  | { kind: 'discard'; player: 'you' | 'opponent'; count: number }
  | { kind: 'gainLife'; player: 'you' | 'opponent'; amount: number }
  | { kind: 'loseLife'; player: 'you' | 'opponent'; amount: number }
  | { kind: 'pump'; target: TargetFilter | 'self'; power: number; toughness: number; duration: Duration }
  | { kind: 'grantKeyword'; target: TargetFilter | 'self'; keyword: Keyword; duration: Duration }
  | { kind: 'tap'; target: TargetFilter }
  | { kind: 'untap'; target: TargetFilter }
  | { kind: 'addCounter'; target: TargetFilter | 'self'; counter: '+1/+1' | '-1/-1'; count: number }
  | { kind: 'createToken'; token: TokenSpec; count: number }
  | { kind: 'scry'; count: number }
  | { kind: 'addMana'; colors: Color[] }
  | { kind: 'returnToHand'; target: TargetFilter }
  | { kind: 'sacrifice'; target: TargetFilter }
  | { kind: 'counterSpell' };

export interface TokenSpec {
  name: string;
  power: number;
  toughness: number;
  colors: Color[];
  subtypes: string[];
  keywords: Keyword[];
  art: string;
}

export type TriggerEvent =
  | 'onEnterBattlefield' | 'onDies' | 'onAttack' | 'onBlock'
  | 'onDealCombatDamage' | 'onUpkeep' | 'onCast' | 'onLifeGain';

export interface Trigger { on: TriggerEvent; effects: Effect[]; }

export type StaticAbility =
  | { kind: 'keyword'; keyword: Keyword }
  | { kind: 'staticPump'; filter: TargetFilter; power: number; toughness: number; excludeSelf: boolean }
  | { kind: 'aura'; attachTo: TargetFilter; power: number; toughness: number; keywords: Keyword[] };

export interface ActivatedAbility {
  cost: { mana?: ManaCost; tapSelf?: boolean; sacrificeSelf?: boolean };
  effects: Effect[];
  sorcerySpeed: boolean;
}

/** Static definition, one per oracle card. Immutable. */
export interface CardDef {
  oracleId: OracleId;
  name: string;
  manaCost: ManaCost;
  cmc: number;
  colors: Color[];
  cardTypes: CardType[];
  subtypes: string[];
  power?: number;
  toughness?: number;
  oracleText: string;
  keywords: Keyword[];
  statics: StaticAbility[];
  triggers: Trigger[];
  activated: ActivatedAbility[];
  spellEffects: Effect[];      // instants and sorceries
  targets: TargetFilter[];     // one per required target, in order
  artist: string;
  art: string;                 // art_crop path
  image: string;               // full card path
  producesMana?: Color[];      // lands only
}

/** A specific instance on the table. Mutable through reduce() only. */
export interface CardInstance {
  id: CardId;
  oracleId: OracleId;
  controller: PlayerId;
  owner: PlayerId;
  zone: Zone;
  tapped: boolean;
  summonedThisTurn: boolean;
  damage: number;
  counters: { '+1/+1': number; '-1/-1': number };
  tempPump: { power: number; toughness: number };     // cleared at end of turn
  tempKeywords: Keyword[];                             // cleared at end of turn
  attachedTo?: CardId;                                 // auras
  attacking: boolean;
  blocking?: CardId;                                   // the attacker this creature blocks
  blockedBy: CardId[];
}

export interface PlayerState {
  id: PlayerId;
  life: number;
  library: CardId[];
  hand: CardId[];
  battlefield: CardId[];
  graveyard: CardId[];
  exile: CardId[];
  landPlayedThisTurn: boolean;
  manaPool: Partial<Record<Color | 'C', number>>;
  mulligansTaken: number;
}

export interface StackObject {
  id: string;
  source: CardId;
  controller: PlayerId;
  effects: Effect[];
  targets: CardId[] | 'player0' | 'player1' | null;
  isTriggered: boolean;
}

export interface GameState {
  cards: Record<CardId, CardInstance>;
  defs: Record<OracleId, CardDef>;
  players: [PlayerState, PlayerState];
  active: PlayerId;            // whose turn
  priority: PlayerId;          // who may act
  turn: number;
  phase: Phase;
  stack: StackObject[];
  winner: PlayerId | null;
  rngSeed: number;
  /** Set while resolving, to forbid a trigger enqueuing a trigger. */
  resolvingTrigger: boolean;
}

export type Action =
  | { kind: 'playLand'; card: CardId }
  | { kind: 'castSpell'; card: CardId; targets: CardId[] | 'player0' | 'player1' | null }
  | { kind: 'activate'; card: CardId; abilityIndex: number; targets: CardId[] | 'player0' | 'player1' | null }
  | { kind: 'declareAttackers'; attackers: CardId[] }
  | { kind: 'declareBlockers'; blocks: Array<{ blocker: CardId; attacker: CardId }> }
  | { kind: 'orderBlockers'; attacker: CardId; order: CardId[] }
  | { kind: 'scryDecision'; toBottom: CardId[] }
  | { kind: 'mulligan' }
  | { kind: 'keepHand'; toBottom: CardId[] }
  | { kind: 'tapLand'; card: CardId }
  | { kind: 'pass' };

export type GameEvent =
  | { type: 'DRAW'; player: PlayerId; card: CardId }
  | { type: 'PLAY'; player: PlayerId; card: CardId }
  | { type: 'CAST'; player: PlayerId; card: CardId; targets: CardId[] | null }
  | { type: 'RESOLVE'; card: CardId }
  | { type: 'COUNTERED'; card: CardId }
  | { type: 'TAP'; card: CardId }
  | { type: 'UNTAP'; card: CardId }
  | { type: 'ATTACK'; attackers: CardId[] }
  | { type: 'BLOCK'; blocker: CardId; attacker: CardId }
  | { type: 'DAMAGE'; source: CardId; target: CardId | PlayerId; amount: number; isPlayer: boolean }
  | { type: 'DIE'; card: CardId }
  | { type: 'LIFE_CHANGE'; player: PlayerId; from: number; to: number }
  | { type: 'COUNTER_ADD'; card: CardId; counter: '+1/+1' | '-1/-1'; count: number }
  | { type: 'TOKEN_CREATE'; card: CardId }
  | { type: 'ZONE_CHANGE'; card: CardId; from: Zone; to: Zone }
  | { type: 'SCRY'; player: PlayerId; count: number }
  | { type: 'PHASE'; phase: Phase; active: PlayerId; turn: number }
  | { type: 'TRIGGER'; source: CardId; on: TriggerEvent }
  | { type: 'WIN'; player: PlayerId };

export interface ReduceResult { state: GameState; events: GameEvent[]; }
```

```ts
export type Rng = () => number;

export function makeRng(seed: number): Rng {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function shuffle<T>(items: readonly T[], rng: Rng): T[] {
  const out = [...items];
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    const a = out[i]!, b = out[j]!;
    out[i] = b; out[j] = a;
  }
  return out;
}
```

```ts
import { describe, it, expect } from 'vitest';
import { legalActions, isLegal } from '../../src/engine/actions';
import { createGame } from '../../src/engine/state';
import { TEST_DEFS, TEST_DECK, handOf, giveLands } from '../fixtures';

describe('legalActions', () => {

    const s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);

  it('does not offer a creature the player cannot pay for', () => {
    const s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);
    expect(legalActions(s).some(a => a.kind === 'castSpell')).toBe(false);
  });

  it('offers a creature once enough lands are untapped', () => {
    let s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);
    s = giveLands(s, 0, 'G', 2);
    expect(legalActions(s).some(a => a.kind === 'castSpell')).toBe(true);
  });

  it('refuses sorcery-speed casts when the stack is not empty', () => {
    let s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);
    s = giveLands(s, 0, 'G', 5);
    s.stack.push({ id: 'x', source: 'x', controller: 1, effects: [], targets: null, isTriggered: false });
    const creatureCasts = legalActions(s).filter(a =>
      a.kind === 'castSpell' && s.defs[s.cards[a.card]!.oracleId]!.cardTypes.includes('creature'));
    expect(creatureCasts).toHaveLength(0);
  });

  it('refuses any response once the stack holds three objects', () => {
    let s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);
    s = giveLands(s, 0, 'G', 5);
    for (let i = 0; i < 3; i++) {
      s.stack.push({ id: `x${i}`, source: 'x', controller: 1, effects: [], targets: null, isTriggered: false });
    }
    expect(legalActions(s).every(a => a.kind === 'pass')).toBe(true);
  });

  it('isLegal agrees with legalActions', () => {
    const s = createGame(TEST_DEFS, TEST_DECK, TEST_DECK, 42);
    for (const a of legalActions(s)) expect(isLegal(s, a)).toBe(true);
```

- [ ] **Step 3: Implement**

`legalActions(state): Action[]` enumerates, for the player with priority:

- `playLand` for each land in hand, if `!landPlayedThisTurn`, stack empty, own main phase.
- `castSpell` for each castable card. Sorcery-speed (creature, sorcery, enchantment, artifact
  without flash) requires own main phase and empty stack. Instants and flash cards need only
  priority. Affordability is checked against untapped lands' `producesMana` plus `manaPool`.
- `activate` for each activated ability whose cost is payable.
- `declareAttackers` / `declareBlockers` in their phases.
- `pass` always, unless the game is over.

Targets are enumerated by `legalTargets(state, filter, controller)`, which applies hexproof
(opponent-controlled only) and skips targets whose ward cost the caster cannot pay. **A spell with
a required target and no legal target is not offered at all.**

`isLegal(state, action)` is implemented as a membership check against `legalActions` — this
guarantees the two can never disagree.
